# Blood Bank Management System

## Project Description

Blood Bank Management System is a web-based application developed to manage
blood donors, blood stock, blood donations, blood requests and hospitals.

The system helps in maintaining blood-related information in an organized
and efficient way.

## Features

- Donor Management
- Blood Stock Management
- Blood Donation Management
- Blood Request Management
- Hospital Management
- Blood Search
- Reports
- Notifications
- Admin Management
## Blood Stock Management

The Blood Stock module helps manage available blood groups and
maintain blood stock information in the Blood Bank Management System.
## Technologies Used

- HTML
- CSS
- PHP
- MySQL

## Project Modules

### Admin
Manages the overall blood bank system and its information.

### Donors
Stores and manages donor-related information.

### Blood Stock
Manages available blood groups and blood stock.

### Donations
Manages blood donation records.

### Requests
Manages blood requests.

### Hospitals
Maintains hospital-related information.

### Reports
Provides information and reports related to the blood bank.

### Search
Helps users search for required blood information.

## Project Structure

- `admin/` - Admin related files
- `assets/` - Project assets
- `blood_stock/` - Blood stock management
- `config/` - Configuration files
- `database/` - Database related files
- `donations/` - Donation management
- `donor_offers/` - Donor offers
- `donors/` - Donor management
- `hospitals/` - Hospital management
- `includes/` - Common included files
- `issue/` - Issue related files
- `notifications/` - Notifications
- `public/` - Public files
- `reports/` - Reports
- `requests/` - Blood requests
- `search/` - Search functionality
- `index.php` - Main entry point

## How to Run

1. Install a PHP development environment such as XAMPP.
2. Place the project inside the web server directory.
3. Configure the database according to the project database files.
4. Start Apache and MySQL.
5. Open the project in a web browser.
